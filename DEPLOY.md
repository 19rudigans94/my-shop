# 📋 Руководство по деплою

## ⚠️ КРИТИЧНО: Безопасность

### Удаление чувствительных данных из репозитория

Файл `1.env.local` содержит секретные данные и **должен быть удалён из истории Git**:

```bash
# 1. Удалить файл из репозитория
git rm --cached 1.env.local

# 2. Убедиться, что файл в .gitignore
# (уже добавлено)

# 3. Создать файл .env.local на сервере вручную
# Скопируйте содержимое 1.env.local в .env.local на сервере

# 4. Закоммитить изменения
git commit -m "Удалён файл с секретами из репозитория"

# 5. Если файл уже был закоммичен ранее, очистить историю:
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch 1.env.local" \
  --prune-empty --tag-name-filter cat -- --all
```

### Настройка переменных окружения на сервере

1. Подключитесь к серверу:

   ```bash
   ssh ubuntu@82.115.49.188
   ```

2. Создайте файл `.env.local` в директории проекта:

   ```bash
   cd ~/my-shop
   nano .env.local
   ```

3. Добавьте все необходимые переменные окружения (скопируйте из `1.env.local`)

4. Убедитесь, что файл не попадёт в Git:
   ```bash
   # Проверьте, что .env.local в .gitignore
   cat .gitignore | grep env
   ```

## 🔧 Настройка GitHub Secrets

В настройках репозитория GitHub (`Settings > Secrets and variables > Actions`) добавьте:

- `SSH_PRIVATE_KEY` - приватный SSH ключ для доступа к серверу
- `SERVER_HOST` (опционально) - IP адрес сервера (по умолчанию: 82.115.49.188)
- `SERVER_USER` (опционально) - пользователь для SSH (по умолчанию: ubuntu)

## 🚀 Процесс деплоя

### Автоматический деплой

Деплой запускается автоматически при push в ветку `main`.

### Ручной деплой

На сервере:

```bash
cd ~/my-shop
bash scripts/update-my-shop.sh
```

## 📊 Мониторинг

### Проверка статуса приложения

```bash
pm2 status
pm2 logs my-shop
pm2 monit
```

### Просмотр логов деплоя

```bash
tail -f ~/my-shop-deploy.log
```

## 🔄 Откат к предыдущей версии

Если деплой прошёл неудачно:

1. Найдите резервную копию в `.backup-*` директориях
2. Восстановите `.next` из резервной копии
3. Перезапустите PM2:
   ```bash
   pm2 restart my-shop
   ```

Или откатитесь к предыдущему коммиту:

```bash
cd ~/my-shop
git log --oneline -10  # Найдите нужный коммит
git checkout <commit-hash>
npm run build
pm2 restart my-shop
```

## 🐛 Устранение проблем

### PM2 не запускается

```bash
# Проверьте установку PM2
pm2 -v

# Если не установлен:
npm install -g pm2

# Проверьте конфигурацию
pm2 describe my-shop
```

### Ошибки при сборке

```bash
# Очистите кеш и переустановите зависимости
rm -rf node_modules .next
npm ci
npm run build
```

ls -la .env.local
